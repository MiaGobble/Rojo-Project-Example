# Rojo-Project-Example
This template repository is used for fully managed Rojo projects, featuring some awesome stuff, including:
* Automated game building/publishing
* Automated doc building/publishing
* Lune-based building 
* Easy asset editing
* And more!

To learn more, head to the [documentation site](https://miagobble.github.io/Rojo-Project-Example/) and click the "docs" page.
